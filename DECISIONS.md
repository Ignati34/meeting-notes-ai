# Технические решения

- Один репозиторий и один веб-сервер Node.js; интерфейс без отдельного клиентского фреймворка.
- JSON-файл с атомарной заменой выбран вместо SQLite для малой локальной учебной нагрузки. На сервере файл должен жить на постоянном диске и регулярно копироваться.
- Очередь последовательная и хранится в памяти процесса; статус и результаты сохраняются на диске. При перезапуске незавершённые задачи становятся ошибками, а не висят бесконечно.
- Ручной файл и полученный из Яндекс Диска видеофайл сходятся к `processMeeting()`.
- Аудио создаётся FFmpeg в mono MP3 16 kHz/48 kbps. Транскрипция — OpenAI `gpt-transcribe`; конспект — `gpt-5-mini` и JSON-режим.
- Импорт облака ограничен публичными ссылками Яндекс Диска. OAuth и отслеживание папки не входят в обязательный Pro.
- Секреты остаются в серверном окружении. При заданном `APP_PASSWORD` API требует пароль; рекомендуемый режим публикации — обязательный пароль плюс HTTPS.
- Встреча не передаётся в модель, если извлечение аудио или проверка дорожек не пройдены. При пустой расшифровке конспект не создаётся.
