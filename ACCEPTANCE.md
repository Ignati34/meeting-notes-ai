# Протокол приёмки

Дата проверки: 10 ноября 2026. Рабочая среда: локальный каталог проекта на Windows, Node.js 24.18.0. Учебная запись, OpenAI API-ключ и доступ к Hostinger/GitHub не предоставлены.

## Контрольная точка Lite

| ID | Проверка | Результат | Доказательство / ограничение |
| --- | --- | --- | --- |
| L1 | Реальные MP4 и WebM | Не проверено | Нет пользовательских учебных записей. В коде реализованы серверные проверки MIME, расширения, сигнатуры, видео- и аудиодорожек. |
| L2 | Расшифровка и конспект записи А | Не проверено | Нет записи и ключа; реальные результаты не получены. |
| L3 | Запись Б и пустые категории | Не проверено | Нет записи и ключа. Формат ответа и рендер пустых категорий реализованы. |
| L4 | Обновление страницы и сохранность результата | Частично проверено | API списка и записи возвращает сохранённые данные; тест готового результата после реальной обработки не выполнялся. |
| L5 | Повреждённый файл / видео без аудио | Частично проверено | Загрузил текстовый файл с расширением `.mp4`: сервер сохранил встречу со статусом «Ошибка» и сообщением «Файл не похож на видео MP4 или WebM». Проверка настоящего видео без аудио не выполнялась. |

**Lite-код реализован, но контрольная точка приёмки не пройдена:** нет подтверждения L1–L3 на настоящей записи. Следующий шаг для доказательства — предоставить разрешённый MP4 и WebM (для критериев L1), а также две записи с заранее известными фактами, и настроить API-ключ. Исходные записи остаются вне Git.

Тег `lite-implementation-checkpoint` фиксирует состояние кода Lite с выключенным флагом Pro. Это контрольная точка кода, а не свидетельство прохождения критериев на реальных записях. После неё функции Pro включены отдельным коммитом в том же репозитории.

Проверены `node --check` для серверного и клиентского JavaScript, HTTP 200 для страницы, запрос без пароля (HTTP 401), список с паролем и отказ для неподдерживаемого облачного домена (HTTP 400). Это маршрутные проверки, не доказательство интеграционной работы с облаком или AI.

Публикация не выполнена. Для неё нужны доступ к GitHub-репозиторию, Hostinger VPS/CloudPanel и домену, пароль приложения и OpenAI API-ключ. Учебное облако должно выдавать публичную скачиваемую ссылку без обхода авторизации.
