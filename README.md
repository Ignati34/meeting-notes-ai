# Протокол — AI-анализатор встреч

Одностраничное приложение для загрузки видеозаписи MP4/WebM, распознавания речи и создания конспекта встречи. Pro добавляет импорт публичной ссылки Яндекс Диска в тот же обработчик. Реальные выводы создаются только из распознанной речи; примеры и демо-ответы не используются.

## Запуск локально

Требуется Node.js 22 или новее. FFmpeg поставляется npm-пакетом `ffmpeg-static`.

```powershell
npm install
Copy-Item .env.example .env
```

Укажите в `.env` собственные `APP_PASSWORD` и `OPENAI_API_KEY`, затем запустите:

```powershell
npm start
```

Откройте `http://localhost:3000`. Обработка использует `gpt-transcribe` для распознавания и `gpt-5-mini` для JSON-конспекта через OpenAI API. Сервис распознавания ограничивает входной аудиофайл 25 МБ; приложение переводит звук в mono MP3 16 kHz/48 kbps и отказывает, если итоговый аудиофайл больше этого лимита. Целевой учебный сценарий — 2–5 минут; явного ограничения длительности нет, лимит задаётся размером видео и аудио.

## Возможности Lite

- Ручная загрузка одного MP4/WebM за раз; сервер повторно проверяет имя, сигнатуру контейнера, видеодорожку и аудиодорожку.
- Автоматическая очередь: извлечение аудио, транскрибация, структурированный конспект (краткое содержание, решения, задачи, открытые вопросы).
- Результаты и статусы сохраняются в `data/meetings.json`; временные видео и аудио удаляются после обработки или ошибки.
- Незавершённые задачи после перезапуска помечаются ошибкой с инструкцией повторной загрузки.

## Дополнения Pro

- Импорт публичных ссылок Яндекс Диска (`disk.yandex.ru/d/...` или `yadi.sk/d/...`). Ссылка на страницу без разрешённого публичного скачивания не поддерживается; скачайте файл вручную.
- Ограниченные HTTPS-хосты и перенаправления, проверка частных IP-адресов, размер и тайм-аут скачивания, URL не возвращается в API и сохраняется в локальной базе только для сопоставления повторов.
- Повтор такой же завершённой или активной ссылки открывает сохранённую задачу; ошибочную ссылку можно подать снова.
- В едином списке видны источник, этап, дата и резюме. Статусы: получение файла, распознавание, AI-анализ, готово, ошибка.

Для Lite оставьте `PRO_ENABLED=false`. Чтобы открыть функции Pro, укажите `PRO_ENABLED=true` в серверном окружении и перезапустите приложение.

Хранилище по умолчанию находится в `data/`. Для сервера задайте `DATA_DIR` на постоянный каталог вне каталога обновляемого приложения и настройте его резервное копирование. Само приложение не публикует материалы встреч; ограничьте доступ паролем `APP_PASSWORD`. Перед публикацией используйте длинный случайный пароль и HTTPS.

## Переменные окружения

См. `.env.example`. Секреты не добавлять в Git. Лимит видео по умолчанию 250 МБ (`MAX_VIDEO_MB`). Можно задать отдельный путь к FFmpeg через `FFMPEG_PATH`.

## Публикация

Для фоновой обработки используйте VPS с постоянным Node.js-процессом, FFmpeg и постоянным диском. Hostinger VPS с CloudPanel и PM2 подходит по модели исполнения. На Hostinger Web/Cloud один запрос ограничен 120 секундами, а постоянно работающие обработчики не поддерживаются, поэтому там нельзя считать эту очередь устойчивой без отдельной доказанной cron-схемы.

Приложение сейчас не опубликовано: в этой среде нет доступа к аккаунту/серверу Hostinger или GitHub. Проект готов к переносу в Git и развертыванию на VPS после настройки секретов и постоянного каталога данных.

## Проверки и ограничения

Фактический протокол в [`ACCEPTANCE.md`](./ACCEPTANCE.md). Для Lite и Pro требуются настоящая согласованная запись и рабочий OpenAI API-ключ. Эти входы не были предоставлены, поэтому фактический AI-результат не заявляется. См. также [`DECISIONS.md`](./DECISIONS.md).
